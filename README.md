GitHub User Finder
Автор: Чаплыгин Константин Павлович

Описание
Приложение для поиска пользователей GitHub с использованием официального API. Позволяет:
искать пользователей по имени;
просматривать основную информацию о пользователе;
добавлять пользователей в избранное;
сохранять избранные пользователи локально в JSON‑файле.

Технологии
Язык программирования: Python 3.x
GUI‑библиотека: tkinter (встроенная)
HTTP‑запросы: requests
Хранение данных: JSON
Управление версиями: Git

Установка и запуск
Предварительные требования
Python 3.8+
Библиотека requests

Currency Converter
Автор: Чаплыгин Константин Павлович

Описание
Приложение для конвертации валют с графическим интерфейсом (GUI), использующее внешний API для получения актуальных курсов. Сохраняет историю операций в JSON‑файл и позволяет её просматривать.

Технологии
Язык программирования: Python 3.x
GUI‑библиотека: tkinter (встроенная)
HTTP‑запросы: requests
Хранение данных: JSON
Управление версиями: Git

Установка и запуск
Предварительные требования
Python 3.8+
Библиотека requests

# Expense Tracker (Трекер расходов)

**Автор:** [Чаплыгин Константин]

## Описание программы

Expense Tracker — это десктопное GUI-приложение для отслеживания личных расходов. Программа позволяет вести учет финансов, фильтровать записи по категориям и датам, а также автоматически подсчитывать сумму расходов за выбранный период. Данные сохраняются в формате JSON для дальнейшего использования.
